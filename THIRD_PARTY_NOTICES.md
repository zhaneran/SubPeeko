# Third-party vocabulary data

`src/subpeeko/data/vocabulary.json` contains normalized, deduplicated English
word heads and their earliest associated learning level, derived from the
junior-high, high-school, CET-4, CET-6, and postgraduate text lists in
[KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary),
revision `731240a848dca14e2cf17510f384312b788863c1`. No definitions, examples,
or phrase translations are included. The source repository supplies the
BSD 3-Clause license reproduced in `src/subpeeko/data/LICENSE-KyleBing.txt`.

The source identifies [kajweb/dict](https://github.com/kajweb/dict) as its
upstream, whose README describes data collected from a third-party vocabulary
application. The provenance and redistribution permissions of the underlying
material should be reviewed before any public package release. These word
lists are learning references, not official exam syllabuses.
